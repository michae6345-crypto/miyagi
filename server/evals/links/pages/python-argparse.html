Argparse Tutorial¶

author:

Tutorial maintainers

This tutorial is a gentle introduction to argparse, the standard library module for command-line parsing. We build one small program, prog.py, a piece at a time, and run it after each change to see what the new code does.

The basics¶

Start with a program that creates a parser and does nothing else. Save it as prog.py:

import argparse
parser = argparse.ArgumentParser()
parser.parse_args()

Run it with --help. Even this empty parser already knows how to describe itself:

$ python3 prog.py --help
usage: prog.py [-h]

options:
  -h, --help  show this help message and exit

Introducing positional arguments¶

A positional argument is one the user must give. Add one called echo and print what it receives. In prog.py, after the parser is created:

parser.add_argument("echo", help="echo the string you use here")
args = parser.parse_args()
print(args.echo)

Now the program needs a word, and prints it back:

$ python3 prog.py foo
foo

Introducing optional arguments¶

An optional argument starts with dashes and may be left out. Add a --verbose flag that only switches something on:

parser.add_argument("-v", "--verbose", action="store_true", help="increase output verbosity")
if args.verbose:
    print("verbosity turned on")

$ python3 prog.py foo --verbose
foo
verbosity turned on

Combining positional and optional arguments¶

Finally, take a number and square it, and let the flag decide how much to say about the answer:

parser.add_argument("square", type=int, help="display a square of a given number")
answer = args.square ** 2
if args.verbose:
    print(f"the square of {args.square} equals {answer}")
else:
    print(answer)

$ python3 prog.py 4 --verbose
the square of 4 equals 16

That is enough to write most small command-line tools. The reference covers subcommands, mutually exclusive groups and more.
