Quickstart¶

This page gets you writing Python for Blender quickly. Blender runs Python scripts from its Text Editor, and the bpy module gives them access to everything in the open file: objects, meshes, materials and operators.

Running your first script¶

Open the Scripting workspace, make a new text block, and type a script that lists the objects in the scene. Name the text block scene_tools.py:

import bpy

for obj in bpy.context.scene.objects:
    print(obj.name, obj.type)

Press Alt-P (or the Run Script button) and the names show up in the system console.

Adding objects¶

Operators are the same actions as the menus. This adds a cube a little above the origin and keeps a reference to it:

bpy.ops.mesh.primitive_cube_add(size=2, location=(0, 0, 1))
cube = bpy.context.active_object
cube.name = "Crate"

Changing properties¶

Every value you see in the Properties editor can be set from Python. Scale the crate and turn it:

cube.scale = (1.0, 1.0, 0.5)
cube.rotation_euler[2] = 0.785

Trying things in the Python console¶

The Python Console is the quickest way to explore. Type at the prompt and the answer prints right away:

>>> bpy.data.objects["Crate"].dimensions
Vector((2.0, 2.0, 1.0))
>>> len(bpy.data.meshes)
2

Making a material¶

Finally give the crate a colour. A material is data of its own, linked to the object:

mat = bpy.data.materials.new("Wood")
mat.diffuse_color = (0.55, 0.35, 0.2, 1.0)
cube.data.materials.append(mat)
