# Awesome Creative Coding [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of resources about creative coding: generative art, data visualization, interaction design and the
> tools people use to make them.

Contributions are welcome! Read the [contribution guidelines](contributing.md) first.

## Contents

- [Books](#books)
- [Online courses](#online-courses)
- [Frameworks](#frameworks)
- [Communities](#communities)

## Books

- [The Nature of Code](https://example.org/noc) - Simulating natural systems with code.
- [Generative Design](https://example.org/gd) - Visualize, program and create with code.
- [Form+Code](https://example.org/formcode) - An introduction to code as a design medium.

## Online courses

- [Creative Coding with p5.js](https://example.org/p5course) - A free video course for beginners.
- [Shader basics](https://example.org/shaders) - A gentle introduction to fragment shaders.

## Frameworks

- [p5.js](https://example.org/p5) - JavaScript library for creative coding, a sister of Processing.
- [openFrameworks](https://example.org/of) - Open source C++ toolkit for creative coding.
- [three.js](https://example.org/three) - JavaScript 3D library.
- [TouchDesigner](https://example.org/td) - Node-based visual programming for real-time content.

## Communities

- [OpenProcessing](https://example.org/op) - Share sketches and learn from others.
- [Creative Coding Discord](https://example.org/discord) - A friendly place to ask questions.
