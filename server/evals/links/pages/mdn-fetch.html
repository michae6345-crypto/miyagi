Using the Fetch API

The Fetch API lets JavaScript make HTTP requests and handle what comes back. In this guide you write a small script that asks a server for JSON, checks that the request worked, and reads the data.

We use Node.js 18 or later, where fetch() is built in, so the whole guide runs in a terminal. Put the code in fetch-demo.mjs.

Making a request

Call fetch() with a URL. It returns a promise for a Response, so write the code in an async function:

js
async function getData() {
  const url = "https://example.org/products.json";
  const response = await fetch(url);
  console.log(response.status);
}

getData();

Checking that the request worked

fetch() only rejects when the network fails. A 404 or a 500 is still a response, so look at response.ok before using the body:

js
if (!response.ok) {
  throw new Error(`Response status: ${response.status}`);
}

Reading the response body

The body arrives as a stream. response.json() reads all of it and parses it as JSON:

js
const json = await response.json();
console.log(json.products.length);

Handling errors

Wrap the work in try / catch so a network failure or a bad status prints a message instead of crashing the script:

js
try {
  const data = await getData();
} catch (error) {
  console.error(error.message);
}

Run the script with Node:

bash
node fetch-demo.mjs
