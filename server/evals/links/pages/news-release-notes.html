Inkwell 4.0 is here

Posted October 28, 2026 by the Inkwell team

Today we're releasing Inkwell 4.0, the biggest update to the static site generator since it launched. Thank you to the 212 people who contributed code, docs and bug reports to this release.

Highlights

  • Builds are up to three times faster on large sites, thanks to a new incremental cache.
  • Themes can now ship their own image pipeline settings.
  • The development server reloads only the page you are looking at.
  • A new plugin hook runs after every page is rendered.

Breaking changes

The configuration key outputDir is now called outDir. Old configs still work for now and print a warning:

// inkwell.config.js
export default { outDir: "public" }

Node.js 18 is no longer supported; Inkwell 4 needs Node.js 20 or later.

Thanks

A release like this is a community effort. Special thanks to our sponsors, who fund the maintainers' time, and to everyone who tested the betas and told us what broke. The full changelog lists every change, with links to the pull requests. See you at the community call next month!
