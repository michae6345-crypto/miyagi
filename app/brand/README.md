# Miyagi brand kit

Everything for the Miyagi look: the bonsai logo (three cuts, light and dark), the outlined wordmark, lockups, the macOS and Windows app icons, favicons, Devpost and social covers, design tokens, a React logo component and the font.

Start with **BRAND.md**: it says which file to use where and the rules for color, type and copy. Open **brand-kit.html** in a browser for the interactive version (hover a part of the tree, show the construction grid).

The assets were generated by `tools/build_kit.py` from the same geometry as the kit page, so the SVGs, PNGs and icons all match.
